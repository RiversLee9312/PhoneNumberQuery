首个正式版本。

- 完全离线查询号码的原始归属地、号段运营商与号码类型。
- 内置 245 个地区的号码规则，中国大陆补充 520,170 条手机号段记录。
- 支持 24 种语言、25 个语言／地区版本与 RTL 排版。
- Kotlin + Compose，采用 Material 3 Expressive，支持 Monet 与 Themed Icon。
- 提供应用许可证和第三方开源许可证页面，项目采用 Apache-2.0。

需要 Android 8.0 及以上。APK 已使用独立正式密钥签名；安装过调试版的用户需先卸载调试版。部分号码仅有国家级信息，携号转网后的运营商可能不同。

附件包括 Release APK 与 SHA-256 校验文件。构建、签名、数据完整性及一加 11 真机验证通过。
