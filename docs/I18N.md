# Internationalization

The app supports 25 locales in total: English plus 24 additional locales. Every localized resource set has the same string keys so the interface remains translated when Android changes the app language.

Android 13 and later use `app/src/main/res/xml/locales_config.xml` to show the supported languages in per-app language settings. The application manifest should reference it with `android:localeConfig="@xml/locales_config"`. Locale resource directories use BCP 47 qualifiers where a region is significant, including `values-b+zh+CN`, `values-b+zh+TW`, and `values-b+pt+BR`. Android resolves Indonesian strings from the legacy `values-in` qualifier; the locale config uses the modern BCP 47 tag `id`, which the validator treats as an alias.

The lookup works offline. Localized copy describes the bundled data and its limits: the reported region and carrier refer to the number's original allocation, and number portability can change the carrier. No wording promises current location or complete coverage.

When adding a locale, copy the complete key set from `app/src/main/res/values/strings.xml`, translate for the target region, preserve format arguments such as `%1$s`, and add the locale tag to `locales_config.xml`. Keep `app_name` and short controls concise, use natural local terms for landline and toll-free service, and keep the offline and accuracy explanations factual. Verify XML escaping for ampersands, angle brackets, and apostrophes before merging. Run `py -3 tools/validate_i18n.py` to check XML, key sets, placeholders, apostrophe escaping, and locale coverage.
